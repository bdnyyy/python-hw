
# Лабораторная работа — алгоритм K-means

## Описание

В данной лабораторной работе реализован алгоритм кластеризации K-means на языке Python.

K-means используется для разделения набора точек на несколько групп (кластеров). Точки внутри одного кластера должны находиться ближе друг к другу, чем к точкам из других кластеров.

Программа работает с двумерными точками, у которых есть координаты X и Y.

Алгоритм написан без использования NumPy и готовых библиотек машинного обучения.

## Как работает алгоритм

1. Задаётся набор точек и количество кластеров `k`.
2. В качестве начальных центров выбираются первые `k` точек.
3. Для каждой точки вычисляется расстояние до всех центров.
4. Точка добавляется в кластер с ближайшим центром.
5. Для каждого кластера вычисляется новый центр как среднее значение координат его точек.
6. Распределение точек и пересчёт центров повторяются, пока центры не перестанут изменяться.

Для ограничения количества повторений установлено максимум 100 итераций.

Если кластер оказался пустым, его центр остаётся прежним.

## Реализация

Алгоритм реализован с использованием объектно-ориентированного программирования.

Создан класс `KMeans`, который содержит:

- `k` — количество кластеров;
- `centers` — координаты центров кластеров;
- `clusters` — списки точек, относящихся к каждому кластеру.

Метод `fit(points)` выполняет кластеризацию переданных точек и возвращает полученные кластеры и их центры.

Для сравнения расстояний используются квадраты евклидовых расстояний. Это позволяет не вычислять квадратный корень, так как для поиска ближайшего центра он не нужен.

## Пример работы

В программе используется следующий набор точек:

```python
points = [[1, 1], [10, 10], [2, 2], [9, 9], [3, 3]]
k = 2
```

После выполнения алгоритма получаются два кластера:

```text
Кластер 1: [[1, 1], [2, 2], [3, 3]]
Центр: [2.0, 2.0]

Кластер 2: [[10, 10], [9, 9]]
Центр: [9.5, 9.5]
```

Таким образом, близкие друг к другу точки попадают в один кластер.

## Запуск программы

Для работы нужен Python 3.

Из корневой папки репозитория выполнить:

```bash
python kmeans_laba/kmeans.py
```

После запуска программа выведет полученные кластеры и координаты их центров.

Для проверки других данных можно изменить список `points` и значение `k` в файле `kmeans.py`.

## Тестирование

Для автоматической проверки используется библиотека `pytest`.

В файле `test_kmeans.py` реализованы три теста:

1. `test_two_clusters` — проверяет правильность разделения точек на два кластера и вычисления их центров.
2. `test_one_cluster` — проверяет работу алгоритма с одним кластером.
3. `test_empty_cluster` — проверяет ситуацию, когда начальные центры совпадают и один из кластеров может оказаться пустым.

Для установки pytest:

```bash
python -m pip install pytest
```

Для запуска тестов из корневой папки репозитория:

```bash
python -m pytest kmeans_laba/test_kmeans.py -v
```

При успешном выполнении всех проверок выводится:

```text
3 passed
```
