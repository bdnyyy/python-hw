# Лабораторная работа: K-means

## Описание проекта

Проект реализует алгоритм кластеризации K-means на языке Python.

K-means разделяет набор точек на заданное количество кластеров. Каждая точка относится к кластеру, центр которого находится ближе всего.

Алгоритм реализован с использованием стандартных списков Python, без NumPy и Scikit-learn.

## Принцип работы алгоритма

1. Случайным образом выбираются начальные центры кластеров.
2. Для каждой точки определяется ближайший центр.
3. Для каждого кластера вычисляется новый центр как среднее арифметическое координат его точек.
4. Шаги повторяются до прекращения изменения центров или достижения максимального количества итераций.

Параметр `seed` позволяет получать воспроизводимые результаты.

## Структура проекта

- `kmeans/algorithm.py` — реализация класса KMeans.

- `kmeans/cli.py` — обработка аргументов командной строки.

- `uv.lock` — зафиксированные версии зависимостей.

## Основные методы класса KMeans

- `__init__()` — задаёт количество кластеров, максимальное число итераций и seed.
- `_init_centroids()` — выбирает начальные центры.
- `_assign()` — определяет ближайший центр для каждой точки.
- `_update()` — пересчитывает центры кластеров.
- `fit()` — обучает модель и возвращает метки кластеров.
- `predict()` — определяет кластеры для новых точек.
- `inertia()` — вычисляет сумму квадратов расстояний от точек до центров их кластеров.

## Запуск программы

Для управления зависимостями используется uv.

Запуск с параметрами:

```bash
uv run --python 3.11 python -m kmeans --samples 300 --k 3 --iter 100 --seed 42
```

Параметры:

- `--samples` — количество генерируемых точек.
- `--k` — количество кластеров.
- `--iter` — максимальное количество итераций.
- `--seed` — значение для воспроизводимой генерации случайных чисел.
- `--elbow` — дополнительное построение графика метода локтя.

Для запуска с методом локтя:

```bash
uv run --python 3.11 python -m kmeans --samples 300 --k 3 --iter 100 --seed 42 --elbow
```

Программа выводит количество точек в каждом кластере и значение Inertia, а также показывает график кластеризации.

## Визуализация

Для построения графиков используется Matplotlib.

Первый график отображает точки разными цветами в зависимости от принадлежности к кластеру. Центры выделяются крестиками.

Второй график реализует метод локтя — показывает зависимость Inertia от количества кластеров. Он помогает подобрать подходящее значение k.

## Тестирование

В проекте используется Pytest. Реализовано пять тестов:

1. Проверка разделения точек на три кластера.
2. Проверка одинаковых результатов при одинаковом seed.
3. Проверка того, что дополнительные итерации не увеличивают Inertia.
4. Проверка работы с разным количеством кластеров.
5. Проверка метода predict.

Запуск тестов:

```bash
uv run --python 3.11 --extra dev python -m pytest -v
```

Проверка качества кода:

```bash
uv run --python 3.11 --extra dev python -m ruff check kmeans tests
uv run --python 3.11 --extra dev python -m ruff format --check kmeans tests
uv run --python 3.11 --extra dev python -m mypy --strict kmeans tests
```
